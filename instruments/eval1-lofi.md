# Evaluation 1 — low-fidelity walkthrough

Superseded as a standalone session: the check now runs as the 5-minute wireframe segment (W1 + W5) inside each combined session, see `session-runsheet.md`. The questions and note sheet below still apply to that segment.

Participants: 3–5. Remote (screen share of wireframe images) or in person (printed). 15–20 min each. Audio recorded, photos or screenshots of the session saved.

Materials: wireframes in `design/wireframes/` (W1 mobility board, W2 mobility detail, W3 ranking, W4 methodology, W5 mobile layout).

Method: guided walkthrough with think-aloud. Show one wireframe at a time. Ask the participant to say what they see, what they would tap/click, and what they expect to happen. Do not explain the interface first.

## Script

Intro: "这些是网站的手绘草图，不是成品。请边看边说出你的想法，说错不存在，我测的是图不是你。"

Per wireframe, in order W1 → W5:

1. What is this screen about? 这个页面是干什么的？
2. Where would you go first to answer: "中国人去哪个国家最容易留下？" (W1)
3. Point at each number you see — what do you think it means? (W1, W2)
4. How would you check how these numbers are computed? (W4 entry point)
5. What is missing on this screen for you?
